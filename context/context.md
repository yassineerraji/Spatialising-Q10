We are working on the design of a machine learning model that allows to predict the Q10 accurately.

Two starting points that motivate our work are as follows:

1. The baseline for our work is a research paper published by Hacopian: https://doi.org/10.1038/s41598-026-45615-w

2. ~2.2 is the currently used fixed Q10 value that we are trying to beat with a spatialised prediction model.

The very goal of our work is to use Hacopian's work to build a model (or set of models) that beat the 2.2 fixed coefficient.

This is therefore a regression task as the value we are trying to predict is continuous.
